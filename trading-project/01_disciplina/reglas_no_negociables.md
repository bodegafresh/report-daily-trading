# Uso de Reglas No Negociables

Las reglas oficiales del sistema se encuentran en:

📁 `00_objetivo_y_reglas/reglas_no_negociables.md`

Este archivo existe para dejar clara una sola cosa:

👉 **Las reglas no se interpretan, se ejecutan.**

---

## Principios de aplicación

- Las reglas se respetan incluso si:
  - el mercado “se ve bien”
  - vengo ganando
  - siento confianza
- No hay excepciones “por esta vez”
- El resultado económico no valida una sesión
- La disciplina es la métrica principal

---

## Definición de sesión válida

Una sesión solo es válida si:

- Se respetaron TODAS las reglas
- Se cumplió la rutina completa
- Se cerró la sesión conscientemente

Si una regla se rompe:
→ **la sesión se registra como inválida**
→ **no se justifica**
→ **no se corrige el mismo día**

---

## Compromiso personal

Yo no estoy construyendo un día bueno.
Estoy construyendo un **sistema sostenible**.

Las reglas existen para protegerme de mí mismo.
